三分鐘快速建置正式雲端服務：

步驟 1：建立 Google 試算表與 GAS

開啟 Google Sheets ➔「擴充功能」➔「Apps Script」，將本專案的 gas_code.gs 完整貼入。

步驟 2：設定免費 Gemini API Key (資安合規)

至 Google AI Studio 免費取得金鑰。在 Apps Script 左側「專案設定」➔「指令碼屬性」新增 GEMINI_API_KEY，金鑰安全儲存於伺服器端，不洩漏給前端。

步驟 3：部署 Web App 並填入上方欄位

在 Apps Script 點「部署」➔「新增部署」➔ 選擇「網頁應用程式」，存取權限設為「所有人」。將獲得的 Web App 網址貼至上方點擊「儲存」即可正式上線！
