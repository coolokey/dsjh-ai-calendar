如何設定正式 Google 試算表與 Gemini API

目前系統處於展示模式，內建完整智慧模擬。若要正式連接學校 Google 雲端試算表與免費 Gemini API，請依照以下三步：

步驟一：建立 Google Apps Script (GAS)

開啟 Google Sheets ➔ 點選「擴充功能」➔「Apps Script」，將本專案的 gas_code.gs 內容複製貼入。

步驟二：設定免費 Gemini API Key (資安合規)

至 Google AI Studio (aistudio.google.com) 免費取得 API Key。在 Apps Script 專案設定中的「指令碼屬性」新增 GEMINI_API_KEY，金鑰儲存於後端，絕不洩漏前端。

步驟三：部署 Web App 並換上網址

點「部署」➔「新增部署」➔ 類型選「網頁應用程式」，將獲得的網址貼至 index.html 頂部的 GAS_API_URL 常數即可！
